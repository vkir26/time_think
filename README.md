# time_think (Время думать)

**time_think** — игра на вопросы: нужно дать как можно больше верных ответов, пока не кончатся раунды или жизни.

Вопросы — сложение двух чисел (1–7). Сложность задаёт число раундов и жизней. Есть регистрация, вход и сохранение статистики сессии.

**Цель игры**
- За ограниченное количество попыток решить как можно больше задач правильно.
**Как играть?**
- В каждом раунде игроку выдается новая задача.
- Игрок вводит ответ.
- Система сообщает, правильно или нет.
- За каждый правильный ответ — +1 балл, за неправильный — 0 баллов, но попытка тратится.
   Игра заканчивается, когда кончились раунды или жизни (зависит от сложности).
- После игры показывается статистика: результат сессии.
- Уровень сложности можно выбрать.
- Результат игровой сессии сохраняется (CLI).

# Функциональность

- Регистрация и вход
- Игра (выбор сложности, раунды/жизни)
- Статистика своих игровых сессий (CLI)
