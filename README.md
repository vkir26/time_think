# time_think (Время думать)

**time_think** — игра на вопросы: нужно дать как можно больше верных ответов, пока не кончатся раунды или жизни.

Вопросы — сложение двух чисел (1–7). Сложность задаёт число раундов и жизней. Есть регистрация, вход и сохранение статистики сессии.

**Цель игры**

- За ограниченное количество попыток решить как можно больше задач правильно.

**Как играть?**

- В каждом раунде игроку выдается новая задача.
- Игрок вводит ответ.
- Система сообщает, правильно или нет.
- За каждый правильный ответ — +1 балл, за неправильный — 0 баллов, но попытка тратится.
 Игра заканчивается, когда кончились раунды или жизни (зависит от сложности).
- После игры показывается статистика: результат сессии.
- Уровень сложности можно выбрать.
- Результат игровой сессии сохраняется.

# Функциональность

- Регистрация и вход
- Игра (выбор сложности, раунды/жизни)
- Статистика своих игровых сессий

# Установка и запуск

Требования: `Python ≥3.14.5`, `uv`. Для веб-запуска — `Docker`.

Нужен файл `.env` с `JWT_SECRET_KEY` и `PASSWORD_PEPPER`.

Локальные зависимости: `uv sync`

Способы запуска:

- веб — `Docker Compose`, `HTTP API` за `nginx`
- CLI — локально через `uv` (игра и статистика)

# Использование

**Основной веб-запуск:**

`docker compose up --build`

- Сервис доступен на `http://localhost` (nginx, порт 80).
- Миграции Alembic контейнер применяет сам при старте.

*Остановка:* `docker compose down`

**Alembic (локально, работа через CLI):**

`uv run alembic upgrade head`

- Создаёт SQLite БД в `files/` и применяет таблицы.

**CLI (локально):**

`uv run python main.py`

- Перед запуском — `uv run alembic upgrade head` и файл `.env`.
- Меню: регистрация, вход, игра, своя статистика.

**HTTP API (локально, без Docker):**

`uv run uvicorn app.web_api:app --reload`

- Сервис: `http://localhost:8000`. Перед стартом — `uv run alembic upgrade head` и `.env`.
- nginx нет, порт 8000, не 80.
- Примеры запросов: [смотреть раздел API](#API)

# Архитектура

main.py — игра в терминале (меню, регистрация, вход, статистика)

app/ — правила игры, HTTP API (FastAPI), работа с БД

auth/ — пароли и токены

files/ — файл базы SQLite

migrations/ — создание и обновление таблиц

Dockerfile, compose.yaml, nginx.conf — запуск в Docker

# API

`/start`, `/answer` и `/my_stats` — заголовок `Authorization: Bearer <token>` после `/signin`.


| Метод  | Endpoint          | Описание                                    |
| ------ | ----------------- | ------------------------------------------- |
| `GET`  | `/`               | Приветствие (JSON)                          |
| `POST` | `/v1/signup`      | Регистрация                                 |
| `POST` | `/v1/signin`      | Вход, выдаёт токен                          |
| `GET`  | `/v1/how_to_play` | Правила                                     |
| `POST` | `/v1/start`       | Начать игру (query `difficulty`: 1–4)       |
| `POST` | `/v1/answer`      | Ответ на текущий вопрос                     |
| `GET`  | `/v1/my_stats`    | Своя статистика (query `page`, `page_size`) |
